Explora GitHub Copilot a lo largo del ciclo de vida del desarrollo de software mediante situaciones realistas, una aplicación completa y un backlog compartido. Trabajarás de forma iterativa para planificar cambios, crear código, probar el comportamiento, revisar solicitudes de cambios y gestionar el trabajo con agentes.

## Escenario

Eres una nueva persona desarrolladora en Tailspin Toys, una empresa ficticia que ofrece financiación colectiva para juegos de mesa con temática de desarrollo. El backlog del equipo ya está registrado como incidencias de GitHub, listas para que elijas una. Incluye trabajo de funcionalidad, como el filtrado y la paginación, y mejoras de calidad, como la accesibilidad y los estándares de código.

## Elige tu entorno

GitHub Copilot está disponible en el entorno en el que trabajas. Elige el que mejor se adapte a tu forma de desarrollar. Cada taller empieza con su propia configuración y usa el escenario compartido de Tailspin Toys.

### [GitHub Copilot CLI][cli]

Usa el asistente de agentes en el terminal. Trabaja con los modos Plan y Autopilot, instrucciones, skills, agentes personalizados, Playwright MCP, Agent Merge y prácticos comandos de barra.

### [Aplicación GitHub Copilot][app]

Ejecuta sesiones de agentes en paralelo, cambia los modos de sesión, colabora en canvas y gestiona incidencias y solicitudes de cambios de GitHub desde la aplicación de escritorio.

### [GitHub Copilot cloud agent][cloud]

Asigna incidencias de GitHub a un agente asíncrono, guía su trabajo, supervisa el progreso y revisa las solicitudes de cambios que abre.

### [Visual Studio Code][vscode]

Usa GitHub Copilot en Visual Studio Code y GitHub Codespaces. Trabaja con el modo de agente de Copilot Chat, servidores MCP y agentes personalizados sin salir del editor.
